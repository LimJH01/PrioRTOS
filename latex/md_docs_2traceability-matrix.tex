\hypertarget{md_docs_2traceability-matrix_autotoc_md118}{}\doxysection{\texorpdfstring{현재 확인된 주요 간극}{현재 확인된 주요 간극}}\label{md_docs_2traceability-matrix_autotoc_md118}

\begin{DoxyItemize}
\item 1차 기준 플랫폼은 QEMU {\ttfamily virt}/\+RV32\+IMC/\+Hart 0이며, FE310 포팅은 별도 범위다.
\item 1차 기준 tick은 10 MHz에서 10,000 count인 1 ms이며, 현재 코드는 interval 값만 정렬되고 timer 처리 경로는 추가 구현이 필요하다.
\item ready bitmap의 요구 타입/비트 의미와 구현({\ttfamily uint32\+\_\+t}, task slot 기준)이 다르며 최고 우선순위 선택도 상수 시간 CLZ가 아니라 슬롯 순회다.
\item 최종 기준은 4단계 mutex 중첩이지만 정적 Mutex 전환과 중첩 검사, IPCP 동작 및 blocking bound 자동 검증은 아직 남아 있다.
\item 현재 {\ttfamily verification/} 검사 파일과 자동 테스트가 없으므로 위 {\ttfamily TC-\/\texorpdfstring{$\ast$}{*}}는 모두 추후 구현할 검증 사례다. 
\end{DoxyItemize}
