Prio\+RTOS는 동적 메모리와 범용 네트워크 스택을 배제한 단일 코어 하드 실시간 마이크로커널이다. 목표 도메인은 차량 전장, 항공·우주 제어기 및 초정밀 산업용 드라이브다.

핵심 원칙은 다음과 같다.


\begin{DoxyItemize}
\item 런타임 {\ttfamily malloc}/{\ttfamily free}를 금지하고 모든 커널 상태와 스택을 정적으로 배치한다.
\item {\ttfamily g\+\_\+ready\+\_\+bitmap}은 {\ttfamily task\+\_\+id == base\+\_\+priority == bit index} 직접 매핑을 사용한다.
\item LSB De Bruijn 선택기는 Guard Bit 31을 연산 시점에 합성하여 빈 Ready 큐에서도 분기 없이 IDLE을 선택한다.
\item Mutex 보유 태스크는 Top-\/\+Half와 Bottom-\/\+Half 모두에서 선점되지 않는다.
\item Mutex 보유 중 {\ttfamily sleep}, semaphore wait, yield는 금지한다.
\item Mutex의 유효 priority shadowing과 LIFO 복원은 최대 4단계로 제한한다.
\item Timer ISR은 직접 문맥 전환하지 않고 MSIP Bottom-\/\+Half에 위임한다.
\item Pending MSIP는 Bottom-\/\+Half에서 Mutex 보유 여부를 다시 검사한다.
\item Crash\+Dump를 제외한 순수 스케줄링 정적 RAM은 2,976B이며, Crash\+Dump 24B를 포함한 전체 정적 RAM은 3,000B다.
