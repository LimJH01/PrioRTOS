{\ttfamily DEC-\/001}   &초기 대상 플랫폼   &QEMU {\ttfamily virt}는 CLINT/\+UART 메모리 맵과 단일 hart M-\/mode 실행 환경을 제공한다.   &{\bfseries{확정\+:}} 1차 기준은 QEMU {\ttfamily virt}, Hart 0 단일 코어, M-\/mode flat model, RV32\+IMC ({\ttfamily -\/march=rv32imc\+\_\+zicsr -\/mabi=ilp32})로 한다. {\ttfamily DEC-\/002}   &최대 태스크 수   &{\ttfamily MAX\+\_\+\+TASKS}는 32이다. 현재 응용 태스크는 슬롯 1, 2에 등록되고 슬롯 31은 idle로 사용된다.   &선택\+: 32개 슬롯을 지원한다. 슬롯 31은 idle, 슬롯 0..30은 응용 태스크에 배정한다.   &{\ttfamily TASK-\/001}, {\ttfamily SCHED-\/002}, {\ttfamily SCHED-\/004}    \\\cline{1-5}
{\ttfamily DEC-\/003}   &우선순위 방향과 동률   &작은 숫자가 높은 우선순위이며, 기본 우선순위는 슬롯에 대응한다.   &구현 정책\+: 유효 우선순위 숫자가 더 작은 READY 태스크만 현재 태스크를 선점한다. 동률이면 현재 RUNNING 태스크를 유지하며, 현재 태스크가 runnable이 아니면 슬롯 번호가 작은 태스크를 선택한다. round-\/robin은 하지 않는다.   &{\ttfamily TASK-\/003}, {\ttfamily SCHED-\/001}, {\ttfamily SCHED-\/002}, {\ttfamily SCHED-\/005}    \\\cline{1-5}
{\ttfamily DEC-\/004}   &태스크 구성 시점   &스택은 정적 배열이지만 {\ttfamily \doxylink{prio__rtos_8h_aefad3e5130121500bb004e7ca315e89e}{task\+\_\+create()}}가 부팅 중 호출된다.   &구체화 제안\+: boot 초기화 중 등록하고 {\ttfamily \doxylink{prio__rtos_8h_a5d79d14e4f5972ce977309150daf4f06}{priortos\+\_\+start()}}에서 설정을 동결한다. 시작 뒤 생성/삭제는 오류로 거부한다.   &{\ttfamily TASK-\/002}, {\ttfamily TASK-\/003}    \\\cline{1-5}
{\ttfamily DEC-\/005}   &타이머 주기/timebase   &\doxysectlink{md_docs_2master-spec-v2_82_84}{master-\/spec-\/v2.2.4}{0}는 10 MHz timebase와 1 ms tick을 확정하고, \href{../bsp/clint.h}{\texttt{ bsp/clint.\+h}}는 {\ttfamily TIMER\+\_\+\+INTERVAL=10000ULL}을 사용한다.   &{\bfseries{확정\+:}} 1차 QEMU 기준 timebase는 10 MHz, 논리 tick은 1 ms, {\ttfamily TIMER\+\_\+\+INTERVAL=10000ULL}이다. 실제 보드에서는 timebase를 별도로 측정하고 포팅 설정으로 분리한다.   &{\ttfamily TIME-\/001}, {\ttfamily TIME-\/002}, WCET 및 응답시간 분석    \\\cline{1-5}
{\ttfamily DEC-\/006}   &태스크 period/deadline 정책   &현재 태스크 예제에는 주기·deadline 메타데이터가 없다.   &구체화 제안\+: 각 task 설정에 period 또는 minimum inter-\/arrival, relative deadline, WCET, release jitter, 자원 목록을 요구한다. 초기 response-\/time 분석은 constrained deadline({\ttfamily D\texorpdfstring{$<$}{<}=T}) 및 jitter 0으로 제한하고 다른 경우 별도 분석법을 승인한다. 각 수치는 workload와 대상 플랫폼으로 정한다.   &{\ttfamily TIME-\/003}, {\ttfamily TIME-\/\+DET-\/002}, {\ttfamily ERR-\/003}    \\\cline{1-5}
{\ttfamily DEC-\/007}   &동기화 프로토콜의 정확한 변형   &현재 \href{../kernel/ipcp.c}{\texttt{ kernel/ipcp.\+c}}는 동적 ID 기반 waiter handoff 변형이다.   &{\bfseries{확정\+:}} 최종 구현은 정적 {\ttfamily mutex\+\_\+t}, ceiling shadowing, LIFO priority 복원, 최대 4중첩, Mutex 보유 중 blocking 금지로 통일한다. 현재 {\ttfamily ipcp.\+c}는 과도기 구현이며 후속 Mutex 모듈에서 대체한다.   &{\ttfamily IPC-\/001}–{\ttfamily IPC-\/004}, {\ttfamily INV-\/\+MUT-\/010}, {\ttfamily INV-\/\+SYN-\/013}    \\\cline{1-5}
{\ttfamily DEC-\/008}   &뮤텍스 획득 시 차단 동작   &lock할 수 없는 태스크는 해당 mutex의 고정 waiter bitmap에 등록되고 BLOCKED가 된다.   &unlock 시 모든 적격 waiter를 유효 priority 오름차순(숫자가 작은 순서), 동률 slot 오름차순으로 재평가하고 소유권을 READY 전환보다 먼저 이전한다. 경로는 구현됐으며 자동 테스트가 필요하다.   &{\ttfamily TASK-\/004}, {\ttfamily TIME-\/002}, {\ttfamily IPC-\/004}    \\\cline{1-5}
{\ttfamily DEC-\/009}   &오류/안전 상태 정책   &panic은 인터럽트를 끄고 UART 메시지 후 WFI 루프에 진입한다.   &구체화 제안\+: prototype panic은 non-\/returning safe halt, deadline miss 정책은 별도 필수 설정으로 두며 설정 없이는 deadline 감시/제품 수용을 금지한다. 제품의 reset/외부 안전 신호 정책은 위험 분석 후 승인해야 한다.   &{\ttfamily ERR-\/001}–{\ttfamily ERR-\/003}    \\\cline{1-5}
{\ttfamily DEC-\/010}   &스케줄러 자료구조와 시간 상한   &{\ttfamily g\+\_\+ready\+\_\+bitmap}은 {\ttfamily uint32\+\_\+t} 슬롯 비트맵이며 스케줄러는 유효 priority 기준으로 {\ttfamily MAX\+\_\+\+TASKS} 슬롯을 순회한다. IPCP도 {\ttfamily MAX\+\_\+\+MUTEXES}와 {\ttfamily MAX\+\_\+\+TASKS}의 고정 상한을 순회한다.   &구현 정책\+: 기존 비트맵은 task slot 식별/\+READY 상태용으로 유지하고, effective priority 검색에는 순회를 사용한다. 현재 {\ttfamily MAX\+\_\+\+TASKS=32}; 고정 상한에 따른 실행시간은 타깃에서 측정한다.   &{\ttfamily TASK-\/001}, {\ttfamily TASK-\/004}, {\ttfamily SCHED-\/004}, {\ttfamily TIME-\/\+DET-\/001}–{\ttfamily TIME-\/\+DET-\/003}    \\\cline{1-5}
{\ttfamily DEC-\/011}   &검증/테스트 수준   &현재 저장소에는 자동 테스트 및 정형검증 구현이 확인되지 않는다.   &구체화 제안\+: HOST는 순수 로직, QEMU는 RV32 기능/트랩, TARGET은 보드별 timing 검증으로 분리한다. 우선 단위·\+QEMU 테스트와 trace matrix를 만들고 IPCP 불변식 CBMC는 IPCP 구현 이후 추가한다.   &{\ttfamily TEST-\/001}–{\ttfamily TEST-\/003}   \\\cline{1-5}
