\hypertarget{md_docs_2implementation-map_autotoc_md34}{}\doxysubsection{\texorpdfstring{권장 바로 다음 작업}{권장 바로 다음 작업}}\label{md_docs_2implementation-map_autotoc_md34}
IPCP의 lock/unlock, ceiling 기반 대기자 wakeup, 유효 우선순위 승격/복구와 동순위 비선점 규칙을 먼저 자동 테스트한다. 이어서 scheduler/semaphore 상태 전이와 모든 응용 태스크가 BLOCKED가 된 경우 idle fallback을 검증한다.\hypertarget{md_docs_2implementation-map_autotoc_md35}{}\doxysection{\texorpdfstring{확인 시 주의할 점}{확인 시 주의할 점}}\label{md_docs_2implementation-map_autotoc_md35}

\begin{DoxyItemize}
\item {\ttfamily g\+\_\+ready\+\_\+bitmap}의 C 타입은 32비트이며 비트는 태스크 슬롯을 나타낸다. 현재 선택은 {\ttfamily MAX\+\_\+\+TASKS} 순회 방식이며 실행시간 상한은 타깃에서 측정해야 한다.
\item {\ttfamily g\+\_\+ready\+\_\+bitmap}은 슬롯을 나타낸다. block 시 해당 슬롯 비트를 제거하고 wake 시 복구하며, RUNNING 태스크도 bitmap에 포함한다.
\item 1차 기준은 10 MHz timebase의 1 ms tick이며 {\ttfamily TIMER\+\_\+\+INTERVAL=10000ULL}로 정렬됐다. 실제 timer tick 처리와 overrun 검증은 아직 남아 있다.
\item 트랩의 system stack과 {\ttfamily mscratch} 접근 경로가 코드에 있지만, 반복 선점·가드 손상·레지스터 보존 테스트를 통과하기 전에는 보호 기능 검증 완료로 보지 않는다.
\item Makefile 타깃 이름이 존재하는 것만으로 CBMC/trace 실행 파일이나 검증 결과가 존재한다고 판단하지 않는다. 
\end{DoxyItemize}
